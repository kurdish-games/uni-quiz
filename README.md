# Uni Quiz — Developmental Psychology & English Morphology

A cozy, bilingual (**English & Central Kurdish / کوردی ناوەندی**) 4-answer university quiz web app built for sharing with classmates on **Phone, Tablet, Laptop, and PC**.

## Included Course Material
- **Developmental Psychology** (Infant & Child Lecture Notes, pp. 1–8) — 27 questions across 3 difficulty tiers
- **English Morphology (ENG226)** (Morphemes, Affixation & Clipping, Modules 1 & 3) — 27 questions across 3 difficulty tiers
- **Both Subjects Mixed** — All 54 questions shuffled into a 15-level study run

## Features
- **Cozy Warm Console UI**: Flowing silk-wave background that visibly moves and reacts to your cursor/touch (zero dots/circles), warm charcoal & amber-peach glass cards, and bouncy button animations.
- **Full Central Kurdish (Sorani) Support**: One-tap `EN / کوردی` toggle with RTL layout and everyday natural Kurdish translations alongside key English exam terms.
- **Cozy Audio**: `assets/MainMenu.mp3` with smooth cubic fade-in & fade-out + seamless loop crossfades, paired with bubbly Web Audio UI sound effects.
- **15-Level Study Run**: Safe Checkpoints at Level 5 (`500 pts`) and Level 10 (`1000 pts`), Double-Check answer confirmation, **50:50**, **Ask Class**, **Ask a Mate**, **Keep Score**, and lecture-note explanations after every answer.

## Upload to GitHub Pages
1. Create a new public repo on GitHub (e.g. `uni-quiz`).
2. Upload all files inside this folder (`index.html`, `styles.css`, `js/`, `assets/`, `README.md`) to `main`.
3. Open **Settings → Pages → Deploy from a branch → `main` / `(root)` → Save**.
4. Share your live GitHub Pages URL with your uni mates!
